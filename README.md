# Wedding Website Shell

A pressed-flower letter concept and static implementation for the May 29, 2027 wedding at Berkeley Botanical Gardens.

Open `index.html` in a browser. The first screen is a closed envelope; click the wax seal to break it, open the flap, and raise the card.

Generated assets:

- `assets/concept-pressed-letter.png` - ImageGen webpage concept/spec
- `assets/envelope-spritesheet-source.png` - ImageGen parchment/pressed-flower spritesheet
- `assets/envelope-spritesheet-alpha.png` - chroma-keyed transparent spritesheet
- `assets/envelope-pieces/` - split envelope, seal, and pressed-flower card PNGs used by the animation
- `assets/fonts/great-vibes.ttf` - bundled calligraphic date font
- `new-assets/` - supplied envelope back/front/flap, letter, and seal assets used by the current intro stack
- `assets/letter-envelope-blank.png` - earlier text-free hero artwork reference
- `assets/berkeley-garden-watercolor.png` - garden continuation artwork
