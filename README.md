# Wedding Envelope

```sh
PATH="$NVM_BIN:$PATH" npm run dev
```

Click the seal to open the envelope. The page is intentionally just the envelope animation.

Calligraphy stroke capture tool:

```sh
PATH="$NVM_BIN:$PATH" npm run dev
```

Open `/calligraphy-capture.html`. Captured strokes are saved to localStorage
and the invitation reads them back on the same host when the letter opens.
